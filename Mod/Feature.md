# 功能

## 计算器

- 配方计算器从一个配方列表里面求解需求，配方计算器需要增加，删除，临时禁用，编辑配方的界面,包括设置产物概率，增删产物等等
- 配方计算器的目标可以是配方/具体物品，当是具体物品时，可以设置为自动推导合适的配方
- 配方计算器的结果是多种的，包括简单的物料列表，合成流程序列（每一步怎么合成，合成多少）
- 配方计算器可以自己推断出来合适的配方，通过一套规则组合，例如，定义这个配方的基础开销是2，用了这个材料A的开销是B等等，需要一个规则定义界面
- 配方计算器允许设置喜好的配方/材料/矿词里面的物品等等，需要一个界面或者小窗口选择
- 配方计算器这些配置都是可以单独存储的，并且可以更换，例如配置1 配置2这种，每个配置的规则之类的不一样，所以需要一个规则界面
- 配方计算器需要单独的ui，也需要能类似jei那样能够嵌入其他ui的小窗口一类的功能
- 配方计算器有多种，需要支持切换
- 配方计算器需要一个设置界面，来设置某些配置，例如接受自己增殖的配方等等，用复选框之类的就行
- 配方计算器需要一个上下文界面，大概就是我设置这个配方的工作电压和线圈等级，能够看到它实际运行的效果，包括增产之类的，类似于一个面板设置上下文，然后右边看到原始配方和具体配方之类的
- 配方计算器能够添加库存来源，包括玩家背包，箱子，ae等等
