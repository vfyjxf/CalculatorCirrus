## 2026-11-27 — Planner v3 重写立项与实用化设计校准（Rev 3）

- **完整设计规划与数学建模文档**：[PLANNING-V3-DESIGN.md](./PLANNING-V3-DESIGN.md)（涵盖 v2 代码级诊断、Cirrus API 深度集成、MINLHP 超图数学建模、五桶 Tag 探索、材料一致性、预期优先与库存机会成本混合模型、三层 Base 边界、6 大直观预设与未知科技树多范式求解、机器三态分级与 H1–H7 人类辅助决策、双层配方标签 + JEI 四阶段规范化与批量治理工具、7 大 SPI 与用户数据收集分析闭环）。

### 1. 核心问题与重写方向
- **深度接入 Cirrus API，保持 Core 通用纯粹**：打通 `RecipeApi` 的配方系统标签（`RecipeSystemTag`）、`RecipeProjection` / `Clause`（电压、加热、耐久等上下文变换）、`RecipeConstraint`、`StorageApi` 与 `ExecutionSession`，移除 `planning/core` 内写死的物品/模组词表。
- **平实好懂的双层标签（系统标签 + 常规化配方标签）+ 实用批量筛选过滤工具**：摒弃高心智负担的复杂学术分类，只用直观的 10 类常规化配方标签（正常合成、压缩/解压、换色、变体互换、容器装卸、拆解回收、资源生产、催化增殖、可疑 JEI、垃圾/重复），并配套多条件组合搜索筛选器、“查找相似配方”批量拉黑工具、JEI 分类一键开关面板。
- **务实的资源采集与基础材料（Base）边界**：不搞复杂神秘的多模态曲线——高价值/稀有不可直接采集物直接默认**禁止作为采集原料**；普通可获取资源只朴素区分**“需要玩家手动跑图采集”**与**“基地内现成/自动持续产出”**；支持不同整合包灵活停在各自的大宗基础材料（如铁锭、钢锭等 Base 到此为止，独立矿产线另算）。
- **预期成本优先 + 合理参考库存 + 同类材料一致**：按统一预期成本决策，参考现有库存但不为两三个零碎杂木拆乱整洁方案；遇到 Tag 不盲目停止，主动探索可用生产链，并在整条计划内保持同族材料一致（如优先统一用橡木做木板、木棍）。
- **真正实用的用户辅助决策（重点强化机器与上下文补全）**：支持用户方便勾选/补充**“我有哪些机器”**，在规划中智能区分**“用户已有的机器 / 几步就能顺手做出来的简单小机器 / 造起来很麻烦需要问用户愿不愿意做的大机器”**，并覆盖模具持有、Base 止步切换、Tag 材料偏好、可疑 JEI 配方确认与一键同类拉黑。
- **可扩展用户数据收集与分析接口**：收集用户机器数据、选路与配方拉黑数据、制作需求与实际执行卡点数据，用于本地自动补全习惯与离线分析过滤低质量配方。
